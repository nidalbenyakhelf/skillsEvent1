# 📁 دليل تنظيم الصور والأصول (Assets)

## 1️ الهيكلية المقترحة للمستودع الرئيسي

```
📁 SkillsCraft/ (مستودع GitHub العام)
│
├── 📄 index.html              ← الصفحة الرئيسية
│
├── 📁 assets/                 ← 🆕 مجلد الصور والأصول
│   ├── 🖼️ logo.png            ← لوجو النادي (Skills-Craft)
│   ├── 🖼️ certificate-bg.png ← خلفية/قالب الشهادة (للمصمم)
│   └── 🖼️ hero-bg.jpg        ← (اختياري) صورة خلفية للهيرو
│
├──  main/
│   ├── 📄 main.css
│   └── ⚙️ main.js
│
├── 📁 register/
│   ├── 📄 register.html
│   ├── 🎨 register.css
│   └── ⚙️ register.js
│
└── 📁 plan/
    ├── 📄 plan.html
    ├── 🎨 plan.css
    └── ⚙️ plan.js
```

---

## 2️⃣ مواصفات كل صورة

### 🖼️ `assets/logo.png` (لوجو النادي)
| المواصفة | القيمة |
|----------|--------|
| **الصيغة** | PNG (شفاف) |
| **الأبعاد** | 500×500 بكسل (مربع) |
| **الحجم** | أقل من 200 KB |
| **الخلفية** | شفافة (Transparent) |
| **الاستخدام** | يظهر في الهيدر، صفحة التسجيل، صفحة الخطة |

---

### 🖼️ `assets/certificate-bg.png` (قالب الشهادة)
| المواصفة | القيمة |
|----------|--------|
| **الصيغة** | PNG عالي الجودة |
| **الأبعاد** | **3508×2480 بكسل** (A4 Landscape بدقة 300 DPI) |
| **الحجم** | 1-3 MB |
| **الاتجاه** | أفقي (Landscape) |
| **الاستخدام** | خلفية الشهادة التي تُطبع |

**📌 ملاحظة مهمة للمصمم:**
- اترك **مساحة فارغة** في منتصف الشهادة لوضع:
  - اسم المشارك (في المنتصف)
  - الرقم التسلسلي (في الأسفل)
- لا تضع نصاً في المناطق التي سيُكتب عليها الاسم والرقم

---

### 🖼️ `assets/hero-bg.jpg` (اختياري - للخلفية)
| المواصفة | القيمة |
|----------|--------|
| **الصيغة** | JPG (مضغوط) |
| **الأبعاد** | 1920×1080 بكسل |
| **الحجم** | أقل من 500 KB |
| **الاستخدام** | خلفية الصفحة الرئيسية (إن أردت) |

## 3️⃣ كيفية ربط الصور في الكود

### في `register/register.html` (و `plan/plan.html`):
```html
<div class="club-logo">
    <!-- ✅ الرابط الصحيح -->
    <img src="../assets/logo.png" alt="Skills-Craft" 
         onerror="this.style.display='none'; this.nextElementSibling.style.display='flex';">
    <div class="logo-fallback" style="display:none;">
        <i class="fa-solid fa-lightbulb"></i>
    </div>
</div>
```

### في `admin/print-cert.html` (للشهادة):
```javascript
// عند طباعة الشهادة، استخدم الصورة كخلفية
const certificate = document.getElementById('certificate');
certificate.style.backgroundImage = `url('../assets/certificate-bg.png')`;
certificate.style.backgroundSize = 'cover';
certificate.style.backgroundPosition = 'center';
```

---

## 4️⃣ متى وكيف تضيف الصور؟

### 📅 **الخطوة 1: الآن (قبل النشر)**
1. أنشئ مجلد `assets/` في جذر المستودع
2. ضع فيه `logo.png` فقط (ضروري)
3. ارفع المستودع على GitHub

###  **الخطوة 2: لاحقاً (عند جاهزية المصمم)**
1. استلم ملف `certificate-bg.png` من المصمم
2. ضعه في `assets/certificate-bg.png`
3. عدّل كود `print-cert.html` ليستخدم الصورة

---

## 5️⃣ نصائح مهمة للمصمم عند تصميم الشهادة

اطلب من المصمم مراعاة هذه النقاط:

```
┌─────────────────────────────────────────────────────────┐
│  ═══════════════════════════════════════════════════╗  │
│  ║                                                   ║  │
│  ║   [شعار النادي]              [عنوان: شهادة حضور]  ║  │
│  ║                                                   ║  │
│  ║   تشهد منصة ملتقى المهارات الناعمة بأن            ║  │
│  ║                                                   ║  │
│  ║   ═══════════════════════════════════════════     ║  │
│  ║   [مساحة فارغة لاسم المشارك - خط كبير]            ║  │
│  ║   ═══════════════════════════════════════════     ║  │
│  ║                                                   ║  │
│  ║   قد شارك بنجاح في ورشات الملتقى                  ║  │
│  ║                                                   ║  │
│  ║   [التوقيع]          [الختم]        [الرقم]       ║  │
│  ║                                                     │
│  ╚═══════════════════════════════════════════════════╝  │
└─────────────────────────────────────────────────────────┘
```

**المناطق الفارغة التي سيملؤها الكود تلقائياً:**
- ✅ اسم المشارك (في المنتصف)
- ✅ الرقم التسلسلي (في الأسفل يميناً أو يساراً)
- ✅ التاريخ (اختياري)

##  الخطوة التالية

**هل تريدني أن:**
1. **أ)** أضيف كود دعم صورة الشهادة في `print-cert.html` الآن (جاهز للاستخدام لاحقاً)؟
2. **ب)** أنتظر حتى يرسل المصمم التصميم ثم نعدّل الكود؟

أنصح بـ **الخيار A** لأن الكود سيكون جاهزاً مسبقاً، وما عليك سوى استبدال الصورة لاحقاً! 🚀
